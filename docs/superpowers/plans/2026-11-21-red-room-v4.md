## Global constraints

- Model IDs from `.env`. Agent and attacker: `mistral-large-4`, `reasoning_effort="low"`, `max_tokens=800`. Analyst, sibling writer, research agent: `mistral-large-4`, `reasoning_effort="high"`, `max_tokens>=2000`. Fallback `mistral-small-2603` without `reasoning_effort`.
- No Guardian anywhere in the product. `stopped_by` is "agent" or "none".
- Limits: voice 300 s; text 20 player messages or 600 s; idle 60 s.
- Owner instructions max 2,000 characters.
- Cooldown after an arena loss: `ARENA_COOLDOWN_S` (default 600 for the hackathon).
- Retest: up to 5 most recent open failures; each = original + 3 siblings; 3 repeats each; parallel 8; fixed = 3/3 on original and all siblings; adaptive replay max 8 turns.
- Generalisation score = sibling runs blocked / sibling runs tried.
- Owner practice runs never change Elo.
- Public agent data: name, stream, rating, rating deviation, grade, version, stats. Never prompts, transcripts or graphs.
- Fictional brands; no real voices, card numbers or sort codes.

### V4-5 Logbook, analyst, cooldown
- `logbook.record(run)` on every agent loss; `stopped_by`.
- Analyst on the Mistral Agents SDK (`mistralai-agents`; check current docs) or chat completions if the SDK fails in 30 minutes: groups open entries by root cause (use `mistral-embed` similarity to merge), 2-3 quotes each, no fixes. - Cooldown: after an arena loss the agent is hidden from the arena until `cooldown_until`; publishing a version that passes retest clears it.
- Tests: grouping merges similar entries (fake embeddings), analyst output has no "fix" field, cooldown hides and clears.

### V4-6 Retest loop, publish, ratings
- Sibling writer (Large 4 high): 3 variants per failure, same cause, different details/languages; cached.
- Adaptive replay attacker (Large 4 low) with the original transcript as guide, max 8 turns; win check by code.
- `retest.run(agent_id, draft)` → per failure: original + siblings, 3 repeats, parallel 8 → fixed / flaky / still failing; genuine cases newly blocked; generalisation score.
- Fixed failures close and emit `learned` graph events.
- Publish: new version, Elo carries over, rating deviation 200, cooldown cleared.
- New arena loss in a closed group → reopen with flag "fix didn't generalise".
- Tests: labels from fake runs, fixed needs siblings too, generalisation score math, publish keeps rating, reopen on new loss.
